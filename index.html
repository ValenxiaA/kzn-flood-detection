Flood Detection

KwaZulu-Natal flood mapping

🌊

April 2022 Event — U-Net Classification

Tiles 36JTM / 36JUM / 36JTN / 36JUN · 2,897 test patches · UNOSAT reference

A 12-channel fusion U-Net combines Sentinel-1 SAR, Sentinel-2 optical indices, and DEM information to detect flood extent. A 9-channel optical-only U-Net is included as a baseline to compare sensor contribution.

Drought Prediction

SPI-3 forecasting with LSTM

🌿

KwaZulu-Natal and Northern Cape

2000–2024 · CHIRPS rainfall + MODIS NDVI anomaly · 12-month input windows

A two-layer LSTM predicts SPI-3 one month ahead using a chronological 70/15/15 split. The model is trained separately for KwaZulu-Natal and the Northern Cape to support province-specific drought monitoring.
